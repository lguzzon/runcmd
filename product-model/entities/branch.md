# Branch

A feature or support branch managed by the Git Flow helper.

## Information kept

- **Name** — the branch name under its type prefix
- **Type** — feature or support
- **Base branch** — the branch it starts from: develop for a feature, main for a support branch

## States

### Started

The branch exists locally.

### Published

The branch has been pushed to the remote repository.

### Finished

The branch has been merged into its integration branches and deleted.
