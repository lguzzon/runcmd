# Git Flow configuration

The git-flow settings kept in the repository's git configuration.

## Information kept

- **Master branch** — the branch git-flow treats as the master line (main or master)
- **Develop branch** — the integration branch for features
- **Feature prefix** — the branch prefix for feature branches
- **Release prefix** — the branch prefix for release branches
- **Hotfix prefix** — the branch prefix for hotfix branches
- **Support prefix** — the branch prefix for support branches
